# Taskflow Local v0.1.0

An offline Windows task timeline with local language and screenshot input. Manual task management works immediately; model-driven changes always require approval.

## Downloads

- **Taskflow-Local-0.1.0-windows-x64-setup.exe** — recommended Windows x64 installer, approximately 13.9 MiB. Includes the app, pinned llama.cpp runtime, DLLs, and runtime notices.
- **Taskflow-Local-0.1.0-windows-x64-portable.zip** — approximately 24.2 MiB. Extract the whole directory and run `taskflow-local.exe`; keep `runtime/llama/` beside it. App data still lives in the Windows user's application directories.
- **SHA256SUMS.txt** — checksums for both downloads.

Windows x64 and Microsoft Edge WebView2 are required. The build is unsigned, so Windows may show SmartScreen. Quit any older Taskflow instance from its tray menu before installing or opening this build.

## Included

- SQLite task creation/editing, status, read/unread, soft deletion, search, and date/status filters.
- A visible window on launch, single-instance restoration, Open/Quit tray controls, and hide-on-close behavior.
- Desktop reminders while the app remains running, including when hidden in the tray.
- Compact task rows, keyboard shortcuts, and Classic, Slate, Nord, Dracula, and Solarized colour schemes.
- Local model selection: downloaded GGUF files or already installed local Ollama models.
- Gemma text actions and temporary PNG/JPEG screenshot input through its matching projector.
- One validated model action per request, SQL-backed queries, clarification, and approval before task mutations.
- Both source-review passes: permission/save guards, reminder state recovery, synchronized idle shutdown, retained failed inputs, and model/image capability refresh.

## Model setup

The model and image projector are **not included** in either download. Manual task controls work without them.

Use **Settings → Open Models Folder** and follow the [README model setup](https://github.com/S-Srinivasan-06/hacktoberfest-weekend-2026-10-01/tree/v0.1.0#model-file-placement). The tested default files are:

- `gemma-4-E2B_q4_0-it.gguf` — text model, about 3.35 GB.
- `gemma-4-E2B-it-mmproj.gguf` — optional matching image projector, about 987 MB.

After copying files, select **Refresh models**. Model downloads, exact revisions, and hashes are documented in the README. Ollama is optional and separately managed; Taskflow does not install it or pull models.

## Evidence and limitations

The release build completed successfully, including TypeScript checking, Vite bundling, Rust release compilation, and NSIS packaging. The portable archive contains all 32 runtime files/notices and excludes model and database files.

Earlier evidence includes 32 passing unit tests, three mocked browser scenarios, five real Gemma text prompts with a 25-task context, a schema canary, and one real Gemma screenshot example. **Those tests were not rerun after the final code-review fixes, at the user's request.**

Installed Windows tray interactions, native notification delivery, persistence/model lifecycle through the installed UI, and a real Ollama provider still need acceptance checks. Compilation and packaging do not verify those behaviors. Reminders stop when the app quits; there is no Windows Calendar integration. Screenshot input produces one task proposal and does not save image attachments.
